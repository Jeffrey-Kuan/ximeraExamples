An example of various uses of answer.

The command \answer must be in math mode.

Type \(2\). \(\answer {2}\), \(\answer [given]{2}\), \(\answer [tolerance=.2]{\frac {1}{2}}\), \(\int _a^b f(x) \ dx\),
\[ -\frac {1}{\frac {12}{1}}\sum _{n=1}^{\answer {\infty }} n \]
Is \(\ln (x^2+4) = \ln (|x^2+4|)\)? Well
\[ \ln (x^2+4) = \answer { \ln (x^2+4) } \]
and
\[ \ln (|x^2+4|) = \answer { \ln (|x^2+4|) } \]

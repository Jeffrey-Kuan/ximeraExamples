A testbed file for Outcomes.

1 Intended Outcome of Test

In the preamble we use the \outcome command to add an outcome, and add a new outcome with each \outcome command. Then we use the \displayOutcomes command to display the outcomes listed in this file. The command \displayOutcomes takes an optional argument to load an outcome file from a different file (if it exists).

So, in the preamble, we used the following commands to populate the outcomes:

  • \outcome{Answer some questions about some stuff.} 
  • \outcome{Do something productive.} 
  • \outcome{Learn how Questions work maybe.} 
  • \outcome{Maybe other stuff - who knows!} 

The test area should look (approximately) like the following:

Goals for this Section (Hover over me to see!)
At the end of this section, students should be able to...

  • Answer some questions about some stuff.
  • Do something productive.
  • Learn how Questions work maybe.
  • Maybe other stuff - who knows!

So go forth and learn!
